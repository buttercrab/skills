# Request

Design a reference and decision packet for a desktop flood-response coordination desk. Operators are trained dispatchers working repeated eight-hour shifts. At 1280px wide they need to compare about 30 requests: age, location, people affected, assigned crew and stale status. Three severity levels must also work without color. Acknowledging a request must not dispatch a crew; dispatch needs a deliberate separate action and a visible result. Keyboard use, recent-change visibility and undoing an accidental assignment matter more than empty space. Keep the existing labels: New, Acknowledged, Assigned, Resolved. I have seen beautiful sparse portfolio dashboards and would love that level of polish. Find useful references, explain any mismatch, and apply the selection to the main queue plus assignment/recovery states. No app implementation.
