# Frozen matching cohort: 2026-11-07

Eight cases, sixteen independent source/reference-packet and applied-outline trials. This archive contains original final artifacts, instruction snapshots and condition/coordination records. It contains no built UI or acceptance evidence.

- `package-snapshot.json`: one UTF-8 text snapshot of the shared target package, with SHA-256 per file; both arms received its identical library and helper.
- `trials/*/instructions/`: each arm’s actual entrypoint, metadata and references. Baseline uses the prior pilot v1.1 snapshot. Shared card/helper bytes are preserved once above.
- `trials/*/`: request, common instructions, final result, runner work log and receipt record.
- `review-input/*/`: neutral review artifacts and coordinator conversation excerpts. Assistant turns are summaries, user relays are normalized delivered text. They are not full native tool transcripts.
- `artifact-hashes.json`: final trial/neutral artifact hashes frozen before review labels were revealed.
- `corpus-manifest.json`, `run-manifest.json`, `coordinator-events.json`, `review-condition-map.json`: original freeze, dispatch, relay and neutral-label records. Absolute temporary paths record provenance; use these archived relative counterparts when replaying inspection.

Complete upstream pages, search results and remote artwork were **not** snapshotted. Live public source reads varied; source URLs, timing and access outcomes are runner reports. This limits causal comparison. Cards preserve curators’ attributed inspection evidence, which is distinct from each runner’s source access.

The parent protocol/rubric/case/private mapping files preserve the pre-run proposal. Proposal-only order permutations and decoy experiments were not executed in this cohort. No exhaustive internet recall, cost/time advantage, real-person creative satisfaction, rendered design quality, accessibility conformance or physical-device usability is demonstrated.

The earlier execution pilot and its invalidated browser-policy comparisons remain separately preserved in `docs/evaluations/design-pilot/`. No findings here rehabilitate those exclusions.
