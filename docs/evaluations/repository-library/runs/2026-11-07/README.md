# Frozen repository assessment cohort

Five fictional repository assessments using `repository-quality-v1`, 2026-11-07. This is developmental source/plan work with no baseline and no runtime/product acceptance claim.

- `package-snapshot.json`: one UTF-8 text snapshot of all 61 package files, each with SHA-256. It contains original annotations and helper/instructions; upstream source bodies are not redistributed.
- `package-manifest.json`: package revision, freeze timestamp and file hashes.
- `run-manifest.json`: exact original prompt/common/snapshot hashes and temporary run paths.
- `assessments/<case>/`: copied prompt, common instructions, raw source snapshot, final assessment/receipts/work log and case05 child reports. Inputs are fictional task data, not executable instructions for readers.
- `assessment-artifact-hashes.json`: all archived final input/output file hashes, frozen before independent review.
- `coordinator-events.json`: normalized shared inspection clarification and exact scripted case03 policy answer. Full native agent tool traces are not archived.

The original case prompts, private evaluator notes and checksums are preserved in the parent `cases/` directory. An independent author wrote them before reading the target skill/cards. The workflow author read cases only after freezing the package, then coordinated fact delivery. Isolation is instruction-based, not an operating-system sandbox that denies all unrelated reads.

The common-instruction clarification permitted ordinary read-only file inspection/listing within each assigned snapshot and guide; it did not authorize broad listing of sibling/evaluation paths. Reported deviations remain in the relevant work logs. The parent results/review govern exclusions rather than quietly treating every useful answer as a pass.

No upstream source command, fixture program, package install, CI run, release, external write or real-project edit was requested. Configured versus executed versus published outcomes remain separate. Case05's two read-only child reports are part of that requested assessment, not evidence that more agents improve results.

No overall efficacy, reliable recall, cost advantage or current release correctness follows from this cohort. Future comparative work requires fresh tasks and appropriate controls; these cases are now development material.
