# W05 — Write a Korean public notice from a small packet

이 자료는 모두 가상입니다. `service-note.md`와 `reference-label.txt`만 사용해 동네 기록실 입구에 붙일 한국어 안내문을 완성해 주세요. 대상은 처음 온 성인 방문객입니다. 제목과 본문을 포함하고, 휴대전화로 찍어도 읽기 쉽게 짧은 단락이나 목록을 써도 됩니다. 본문은 대략 450–700자면 충분합니다. 글자 수를 맞추려고 내용을 만들거나 반복하지 마세요.

목표는 임시 운영 변경과 방문객이 해야 할 일을 오해 없이 알리는 것입니다. 이미 정해진 운영 방침을 재설계하지 마세요. `reference-label.txt`는 기존 자료 한 점일 뿐 문체를 강제로 따라야 하는 견본이 아닙니다. 필요하면 정보에 맞는 형식을 새로 정하고, 안내문 뒤에 편집 판단을 한두 문장으로 설명해 주세요. 영어 번역은 필요 없습니다. 외부 검색, 실제 게시, 실존 기관이나 작가의 문체 모방은 하지 마세요.

자료에 없는 정책은 지어내지 말고 꼭 필요한 확인 사항만 짧게 물어보세요. 답이 없으면 확인되지 않은 부분을 주장하지 않는 완성안을 내주세요.
