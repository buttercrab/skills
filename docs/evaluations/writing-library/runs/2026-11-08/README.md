# Frozen writing development run

The original package, inputs and outputs are retained for the [protocol](../../protocol.md). No baseline was run.

- `package-manifest.json` hashes all 56 original package files; `package-snapshot.json` preserves their text.
- `run-manifest.json` records six supplied input sets across five independently authored fictional cases and the protocol/package-manifest hashes.
- `drafts/` preserves each run's exact scoped inputs, COMMON/inventory, piece, notes, receipts and work log.
- `coordinator-events.json` records both actual W01 questions and the exact scripted replies delivered. Both question triggers occurred. It is a coordinator reconstruction, not a native transcript or timestamp record.
- `output-manifest.json` freezes all archived input/output files and relays before independent review. Both active and isolated package copies and all runner inputs matched their pre-run hashes.

The answers and drafts are development artifacts. W01-noanswer explicitly leaves author-owned content pending; that permission does not make it publication-ready. Logs/receipts are self-reported and do not establish OS-enforced isolation or complete tool traces. Preserve original judgments if later guidance or drafts change.
