# Writing library development results

Date: 2026-11-08 (Asia/Seoul). Six source-only runs across five fictional cases used frozen `writing-with-intent-v1`. The [protocol](protocol.md), [independent fixture record](fixtures.md), [original package and run archive](runs/2026-11-08/README.md), [review](review.md) and [structured judgments](review.json) preserve separate evidence.

## What was tested

An independent author prepared the synthetic prompts, source facts, drafts and private evaluator notes without reading the package. The workflow author froze 56 package files before reading private case contents. Fresh non-forked runners received exact paths and only their case inputs plus the frozen guide. They produced actual prose, editorial notes, receipts and work logs. The reviewer authored none of those inputs, instructions or drafts.

Both W01 runners asked a consequential author question. The answered branch received the exact scripted belief and supporting event. The unanswered branch received only “Please continue with the information available.” [Actual relays](runs/2026-11-08/coordinator-events.json) are preserved. Other cases did not need clarification. No question-count target was used.

All pre-run input hashes and both copies of the original package matched before output freeze. The output manifest preserves 52 archived files plus the relay hash. Case checksums include private evaluator notes. These checks establish retained-file integrity, not complete native traces or isolation enforcement. Logs and receipts report no network, detectors, publishing, contact, source-program execution or real-project changes.

## Independent acceptance and the scope ambiguity

The independent reviewer accepts five originals: W01 answered, W02, W03, W04 and W05. Minor tightening notes accompany three. It conservatively excludes W01 unanswered from acceptance because its log reports a short local Python snippet used only to edit its owned draft. The protocol's “No source/fixture programs, code” and COMMON's “fixture/upstream programs/code” admit a narrower reading that permits ordinary local editing code. The reviewer applied the broader reading; that original exclusion is retained here, not silently upgraded. There is no reported source/fixture execution, contamination or external effect in that action. The excluded prose remains diagnostic, rather than a sixth accepted run. This is an evaluation-instruction ambiguity, not a demonstrated writing-skill defect.

The original review and outputs are frozen. [v1.1](revisions/writing-with-intent-v1.1/package-manifest.json) changes one reference paragraph after that review: when an author's center remains unknown, avoid filling length with repeated caveats or expanding a neighboring topic; retain useful supported prose and visible author slots, allowing a shorter honest draft. This responds to a concrete editorial limitation, including the diagnostic no-answer output. No new stylistic ban, case-specific template or mandatory questionnaire was added. At revision time the updated guidance had not had a fresh behavioral trial. The separate [fresh follow-up](followup-2026-11-08/results.md) subsequently accepted one new provisional writing case under an explicit local-edit allowance; it does not change the originals' judgments or estimate improvement.

Future trial instructions should explicitly distinguish local output editing from execution of supplied/upstream programs before runners start. Do not retroactively alter this protocol or reclassify its exclusion as a clean accepted run.

Read-only installer discovery lists thirteen skills, including this package; no global installation was performed.

## Limits

There was no baseline, randomization, human author/reader panel, comprehension test or publication study. The two W01 branches are separate agent runs; their contrast illustrates different information boundaries and does not estimate a causal question benefit. No detector, grammar service or upstream article/tool program was run. Craft references during trials were local annotations rather than fresh upstream inspections, and runners disclosed that limit.

The cohort is small and deliberately constructed. It can expose development defects and demonstrate particular decisions on these inputs, not prove creativity, reliability across all genres, human satisfaction or effectiveness of this skill. These exposed cases are development material; future comparisons require fresh cases and controls. Original outputs and judgments must remain unchanged by subsequent guidance revisions.
