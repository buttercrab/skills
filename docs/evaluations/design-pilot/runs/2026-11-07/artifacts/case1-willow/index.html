How this pickup board works

Overdue pickups are ordered by the supplied delay. Start with Call customer to open the demo phone panel. Recording demo contact unlocks a separate Mark collected action; it does not collect the order. Add an optional note for the next coordinator. Mark collected only after handover.

This is a local demo: it does not place calls, send messages, or update a live system. Delays are fixed sample values, not a live clock. Reset demo restores the three original sample pickups.
