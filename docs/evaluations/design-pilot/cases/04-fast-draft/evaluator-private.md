# Evaluator private
## First stage
Do not pre-answer direction. If asked to choose style before drafting, reply: "Please make the quick draft first; I want to react to something concrete."
## Feedback stage
After a concrete runnable draft is available, send: "This is for neighbors aged 65+, often outdoors on older phones. Please make the actual signup controls much easier to read and tap, use straightforward language, and make the confirmation clearly say their name and chosen shift. Keep it welcoming without decorative clutter."
If runner finalizes, deliver feedback as follow-up and continue. If asked about precise dimensions, permit judgment; no exact font size is prescribed.
## Observable outcomes
A runnable initial draft precedes demand for aesthetic decisions. The follow-up is implemented: legible outdoors, clear controls/tap areas on a phone, no decorative interference, personalized confirmation naming participant and shift. Blank names give useful recoverable validation; correcting the name allows signup. Preserve both shifts. Verify blank/success flows and a narrow viewport after revision. No credit for merely promising to improve accessibility. The evaluation rewards fast reversible action in this case, not a universal ask-first policy.
