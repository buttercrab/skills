## Inspection method

All visual observations came from my own native Chrome tab created directly at a public HTTPS source. The selected Chrome provider was retained for subsequent source navigation. Each navigation/scroll was followed by fresh accessibility state and a screenshot that was actually viewed. Typical captured width was approximately 1552 pixels. No viewport override or physical-device claim is made.

Sources that initially showed a loading/transition frame were inspected again after a fresh state observation identified the missing loaded content. Those empty or translucent frames were not used as evidence of the design's settled composition. The Stripe Press homepage canvas did not populate meaningfully; a visible book detail link supplied the successful inspected reference, so the card identifies that specific page instead of claiming the whole homepage was viewed.

The only deliberate UI action beyond read-only navigation/scrolling was opening Toss's visible public language menu and selecting Korean. The resulting title, URL, Korean navigation and headline were observed. This did not create an account, submit financial information, place an order or alter a user's account configuration. The card records this narrow interaction separately from its screenshots; it claims no financial flow verification.

No CUA policy denial occurred. No local files, local servers, headless browser route, downloaded assets, signups, purchases, account actions, external messages or product installations were used. The CUA part ended with completion summary `Inspected sixteen visual design references`. Research tabs were not marked as deliverables or handoffs.

The initial source families were selected to contrast character-led learning/consumer identity, text-led communities, professional tools, editorial collections, physical-product commerce, creative worlds, native-screen representations and multilingual composition. Existing UX/visual research informed the selection questions but did not substitute for viewing the current surfaces.

- `Are.na official website connecting ideas` for a community/knowledge contrast.
- `The Pudding official visual essays website`, `Stripe Press official books website`, and `Monument Valley official game website ustwo` for editorial, object and game-world references.
- `Poolsuite official internet leisure website` for the desktop-metaphor candidate; the original public site supplied the evidence, not the secondary description.

Other obvious first-party public domains were inspected directly: Duolingo, Finch, Linear, Raycast, Brilliant, Toss, Things, Kagi and teenage engineering. Search-result snippets and third-party rankings supplied discovery leads only. Claims in the cards derive from the viewed original surfaces. Awards, ratings, health claims, product-performance promises and popularity were excluded as quality evidence.

## Evidence and reuse discipline

All sixteen cards are curated examples with `visual-inspected` evidence; fifteen have public access labels and Monument Valley has partial access. Independent cross-review found its direct `/mv3` deep link returned Page not found, despite the original root navigation successfully rendering that view. The card now links the actual inspected root entry, preserves the observed route and explicitly flags the deep-link instability. A subsequent independent navigation through the exact root `?lang=en` entry also successfully rendered the game-world imagery, corroborating the original observation. No successful direct deep-link reload is claimed.

The three kinds of visual object remain explicit: a public website composition, an embedded app/product representation, and a public interface itself. Only Toss additionally has `interaction-tested`, scoped to language navigation. No native app was installed or operated, and no marketing screenshot establishes its app's current behavior.

No image, font, logo, media file or third-party source package is redistributed by these cards. They link original sources and add original annotations. Asset reuse rights were not established. The source locator/date/method is the maintained receipt; the catalog does not silently turn source material into reusable assets.

## Coverage and residual gaps

This collection supplies real visual contrasts across learning, consumer companions, community/knowledge, professional tools, editorial explanation, publishing, games, leisure, multilingual consumer marketing and physical objects. It is a purposeful selection, not an aesthetic ranking or census of products.

Coverage remains weaker for actual authenticated working screens, full mobile interaction sequences, RTL layouts, lower-bandwidth devices, disabled users' observed journeys, civic interfaces and culturally diverse non-Latin products beyond the Korean/English comparison. Phone/Mac representations are useful visual evidence but do not close those runtime gaps. Future curation should prefer first-party accessible screen/state examples in those areas rather than add more generic SaaS heroes.

No comparative usability, conversion, learning, health, accessibility-conformance or skill-efficacy outcome was measured. A later matching task must inspect the selected source at the scope of its fresh claim and explain why the observed qualities transfer to that person's goal.
