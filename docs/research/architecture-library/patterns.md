## Consequential source qualifications

The monolith discussion is deliberately a paired decision resource: the disputed question is not whether distribution has costs, but whether a team can preserve useful boundaries while learning inside one deployment. No article supplies a calibrated threshold. A small-system route remains valid.

The outbox/saga/retry cards retain different failure boundaries. A local transaction, broker receipt, consumer mutation and external effect need separate reasoning. The cards’ diagram implications are original modeling recommendations, not claims that source images were viewed or a service behaves as drawn.

Several maintained pages use broad slogans or illustrative topologies. Richardson’s database-per-service CAP shorthand and Microsoft caching’s broad CAP/cache statements are not imported as formal guarantees. Azure’s event-sourcing queue example does not establish the acknowledgement/durable-append ordering of a real implementation. These annotations select supported mechanisms while preserving the need for the actual application contract.
