## Coverage and access limits

All annotations avoid prose quotations and full-article paraphrase. Source-derived descriptions are deliberately bounded; Vogue and New Yorker each provide a 100-word allowance, so those cards emphasize original adaptation and narrowly scoped mechanisms. No source article, image, draft body or upstream program is redistributed. Orwell is a classic contrast, not asserted globally public domain: the authorized Foundation page notes continuing copyright in some jurisdictions.

The Gawande card concerns only the opening comparison: incomplete middle reading is not promoted into whole-story analysis. Figures and interactive behavior were not visually or operationally tested. OWID underlying studies, Quanta proofs, and ecological/economic claims were not independently fact-checked; use their writing mechanisms without importing their factual claims as current advice. Personal essays are read as testimony, not independent verification of events. Published correction notes in Quanta are evidence of declared amendments, not inspectable before/after drafts. No empirical effectiveness, medical guidance, AI/human authorship classification or author-voice cloning is claimed.

A GitHub connector request to the Programming Historian HTML history path returned 422; the official GitHub commits API and pinned source endpoint supplied the inspected history and patch. A large initial multi-result response was truncated: only subsequently displayed body passages and selected patches count as inspected. No paywall or access control was bypassed.

## Selection gaps

This set is English-language and does not represent all literary traditions or editorial cultures. It has one classic contrast and two technical revision histories, but no private newsroom editing chain, author interview, audience study or measured before/after comprehension comparison. These absences should guide later research rather than be filled with invented drafts or motives.
