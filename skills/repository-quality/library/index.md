## Evidence limits

Metadata validates declarations and read paths, not the truth of every annotation. Read the selected card and relevant original material before consequential application. Source authority, configured-versus-executed checks, publication evidence and source freshness remain task-specific. Cataloging a repository or tool does not authorize running its code or workflows.
