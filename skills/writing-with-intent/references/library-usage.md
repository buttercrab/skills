# Find writing references without surrendering the piece

Browse the [index](../library/index.md) or [reading paths](../library/PATHS.md), then read relevant examples, guides, foundations, studies or tools. Match genre, reader knowledge, language, evidence and the author's intended voice/purpose. Different resources can supply structure, explanation, evidence handling or a revision method; no one example must govern every layer.

Optional stdlib-only commands from the skill directory:

```sh
python3 scripts/catalog.py facets --status curated
python3 scripts/catalog.py list --kind example --status curated
python3 scripts/catalog.py find "revision" --status curated
python3 scripts/catalog.py list --language korean --status curated
python3 scripts/catalog.py show RESOURCE_ID
```

Use an exact index ID for `RESOURCE_ID`. Direct Markdown/scoped file reading works too. `--root /path/to/skill` precedes the subcommand if needed. [Vocabulary](../library/VOCABULARY.md) and `facets` reveal actual labels.

Text search matches case-insensitive literal substrings in metadata/source locators/annotations, including mismatch paragraphs; every term must occur. Facets match exact labels. Repeated task/genre/language/context values require all; repeated kind/status/availability values permit alternatives. Results show matched fields, not a ranking of beauty, authorship or reader benefit. An empty query result is not evidence that the internet lacks a suitable example.

For material reference use, identify the inspected portion, useful mechanism, contextual mismatch and resulting choice. A final article is not a record of its drafts. An author interview is a reported process account, not an outcome study. A local annotation does not repeat its curator's primary inspection. Whole-piece structure claims require corresponding body access; if access is partial, narrow the claim or retain the source as a lead.

Choose examples that help the author express a preference or solve a craft problem. Do not impose a mandatory style vote when the brief is complete or judgment delegated. Preserve an unexpected direction and update the search framing. A narrow copy edit need not research examples at all.

Use general techniques and original content, not a named living author's signature voice or copied protected passages. Link to sources and give precise locators rather than reproducing full articles. Broaden primary discovery for missing/stale evidence, keeping new leads separate from inspected support. Referenced guides/tools are not authority to install software, upload private drafts, invoke detectors, contact sources or publish.
