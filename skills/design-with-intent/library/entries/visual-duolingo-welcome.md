# Duolingo: character-led learning welcome

## When to use

Use as a visual reference for a learning or community product that should feel approachable while making a first action obvious. It is especially relevant when an existing character universe is part of the brief.

## What to inspect

Inspect the desktop welcome composition: relationship between the character collage, heading and two action choices. Compare the green primary action with the quiet returning-user alternative. This inspection covers the public website hero, not a lesson screen.

## What to borrow and adapt

Borrow the coordination of illustration, friendly type and a small decision set. The cast gives the subject a social world while the actions stay legible. For a local learning club, an original host or member illustration could serve the same invitation role; choose it with the person rather than automatically adding an owl or reward system.

Adapt character maturity, language and action labels to the audience. The primary task should determine what receives emphasis. Pair with a real signup/correction pattern if the project needs a transaction.

## Mismatches and limits

This is not a reference for dense expert work or proof that mascots improve learning. Do not infer current app navigation, progression, accessibility or conversion from the screenshot. The illustration, logo and proprietary typography are not supplied for copying. The public website can change; re-inspect before making a fresh visual claim.
