# Excalidraw: editable low-fidelity relationship sketches

## When to use

Select Excalidraw when an editable rough arrangement, relationship diagram or low-fidelity flow would help the person react to an idea. It can keep discussion focused on structure and alternatives before fine typography or component styling dominates the conversation.

## What to inspect

Read the distinction between the editor package and hosted application, export options and the SDK FAQ. The package does not automatically provide the hosted service’s collaboration behavior. Check what workspace and sharing authority the task actually provides.

## What to borrow and adapt

Borrow a deliberately small sketch: actors, important content groups, primary actions and transitions with labels explaining their role. Compare two structures using the same real content. A hand-drawn appearance can signal provisionality, but explicitly state what is and is not decided; visual roughness alone does not guarantee open critique.

## Mismatches and limits

A diagram’s attractiveness does not establish a good flow, and an exported image does not preserve an interactive application. Hosted collaboration, share links and integrations can have external effects. Selection is not permission to create a shared room or publish a drawing. Source documentation was inspected; no canvas, export, collaboration session or embedded implementation was executed.
