# Typography: distinguish preference, metrics and reading performance

## When to use

Use when selecting typography for sustained reading, interpreting a readability claim, or deciding whether a brand font conflicts with the actual reading task.

## What to inspect

In Legge/Bigelow, distinguish nominal type size, glyph metrics and visual angle. In Wallace, inspect font assignment, size normalization, exclusions, remote measurement and the within-reader comparison. The catalog preserves a prior inspected historical study, not a fresh prospective personalization test.

## What to borrow and adapt

Assess actual text at intended rendering sizes, scripts, devices and viewing conditions. Separate preference from reading effectiveness and from interface hierarchy. Preserve user adaptation and investigate a real problem before imposing personalization controls.

For a long-form club, test representative passages and long titles, then consider navigation and save controls separately. A font that suits a brand heading need not be the same role as reading text.

## Mismatches and limits

Do not promise the paper's observed fastest-versus-slowest difference as a deployable speed gain. The main study did not sample every font for every reader, excluded reading disabilities and did not find one universally fastest font. It does not require an app font picker or establish that serif/sans, novelty or one CSS size causes success. Original endpoints need access verification before quoting exact measurements.
