# Impeccable: surface modes and focused design commands

## When to use

Select this when the task needs a design procedure matched to the surface’s job: persuading, operating, reading or experiencing. Its focused commands can help distinguish a UX plan, a technical audit, a copy repair and a visual replacement instead of treating every request as a new landing page.

## What to inspect

Read Modes and routing, then only the applicable command reference. The shape reference is a planning-only interview and brief workflow. The canonical source template is skill/SKILL.src.md at this revision; the README identifies craft as a deprecated alias. Registry descriptions can lag.

## What to borrow and adapt

Borrow the separation of surface purpose from the overall product category and the distinction between preserving refinement and replacing a visual world. Use the actual brief and existing interface as authority. For a developer tool, its marketing page, working editor and documentation can need different treatments while sharing identity.

## Mismatches and limits

The suite includes launcher binaries, optional downloads, hooks and project artifact writes. Its README says a new design fetches directions from the hosted catalog even with telemetry disabled; optional anonymous telemetry records directions shown and selected. It also says Claude Code hooks can run outside model approval and download the engine. These are source-described effects, not independently audited behavior; none were executed, and selection does not authorize them. Its command workflow and craft bans require deliberate adoption, not automatic precedence over user constraints. A command score is heuristic, not evidence of usability. No produced UI or efficacy comparison was inspected.
