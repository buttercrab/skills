# Separate visual appeal from the task being measured

## When to use

Use when a reference is called universally clean, when a team infers user nationality from aesthetic preferences, or when a visually quiet screenshot is offered as proof that a product will be easier to use.

## What to inspect

Compare the actual tasks: brief appeal ratings versus rapid target finding. Examine sampling, language instructions, different-site stimuli and the distinction between main search and recall analyses. Group-level correlations are different from predictions about an individual.

## What to borrow and adapt

Name the desired outcome before evaluating visual variants. Use visual inspection for hierarchy and character, task observation for retrieval/recovery, and intended-reader judgment for relevance. Remove unnecessary competition for attention while preserving information needed for comparison.

A dense operations table and an exploratory cultural publication can need different compositions even for the same person. The useful question is what attention and work each presentation supports.

## Mismatches and limits

The studies do not prove a universal airy layout, one ideal density, or a style for every person from a particular country. Different real websites vary in more than complexity. A short screenshot exposure does not test learning, error recovery, keyboard operation or prolonged reading. The card is evidence for choosing the right evaluation, not a source of visually inspected product examples.
