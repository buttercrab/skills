# Supplied-source synthesis

Use this mode when the user names the evidence set: links, connected documents, attachments, repository files, or reports.

## Acquire without substituting

Inventory the requested sources and preserve the mapping from original inputs to acquired content. Deduplicate aliases, redirects, and repeated attachments without losing the user's inputs. For each source, know whether it was acquired, partly acquired, blocked, failed, or not attempted. Keep this inventory lightweight for a short brief; expose it when access gaps or a completeness request make it useful.

Use source identifiers that survive reproduction: document/page ID, canonical URL, repository path and commit, paper identifier, or report edition. Record retrieval time for mutable material when relevant. Acquire attachments needed to interpret the requested source; distinguish additional corroboration from the original evidence set.

If a requested private source is inaccessible, explain exactly what could not be read. Continue the supported portion when useful, and explain which conclusions remain blocked. Ask for access only if the missing source is necessary to answer the user's question. Do not replace inaccessible content with a similarly titled public page, snippet, or memory.

## Reconcile at the claim level

Extract claims relevant to the question rather than summarizing every source sequentially. Preserve locators such as a section, page, table, timestamp, cell range, or verified code line. For relationships among resources, check their identities and sequence: a proposal, approval, implementation, and verification receipt are different evidence even if they share a title.

For a disputed claim, identify each account, its date and scope, and the evidence it offers. A later source can supersede an earlier specification without proving implementation. An authoritative policy can settle what is required without proving that it happened. State the distinction that matters to the answer.

Where corroboration is needed, search narrowly and identify the new source as additional evidence. Do not silently expand a fixed-source assignment into an ecosystem survey.

## Explain the answer's limits

Deliver the synthesis with citations and consequential conflicts or unknowns. If all requested sources could not be acquired, distinguish the supported answer from the unmet source coverage. A missing source blocks a particular conclusion only when that conclusion depends on it; a partial acquisition is never represented as reading the complete resource.
